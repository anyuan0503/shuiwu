# 水务监测分析系统 · 腾讯云+域名 上线操作手册

目标：在腾讯云 Ubuntu 22.04 上部署系统，通过域名 `shuiwufenxi.top` 访问。

> 全程按小节顺序执行，每节内的命令可复制粘贴。标注【控制台】的在腾讯云网页操作，其余为服务器终端命令。

***

## 0. 前置确认

* 服务器系统：Ubuntu 22.04（x86\_64）

* 公网 IP 记好，下文用 `<IP>` 代替

* 域名：`shuiwufenxi.top` 已注册

***

## 1. 域名解析（【控制台】DNSPod/云解析）

1. 打开腾讯云控制台 → 云解析 DNS → 找到 `shuiwufenxi.top`。
2. 添加记录，两条：

| 主机记录 | 记录类型 | 记录值    | TTL |
| ---- | ---- | ------ | --- |
| @    | A    | `<IP>` | 600 |
| www  | A    | `<IP>` | 600 |

3. 生效检查（本机终端）：

```bash
ping shuiwufenxi.top
```

能解析出 `<IP>` 即成功。

***

## 2. ICP 备案（【控制台】腾讯云备案）

> 大陆服务器用域名在 80/443 对外服务必须备案，否则访问被腾讯云拦截。

1. 控制台 → 搜索"备案" → 进入备案系统，按引导填写主体与网站信息。
2. 提交后等待管局审核（一般 2 周左右）。
3. 提交前可用 IP 验证系统；下证后再切域名访问。

***

## 3. 安全组放行端口（【控制台】云服务器 → 安全组）

新建或编辑安全组，添加入站规则放行：

| 协议/端口    | 来源        |
| -------- | --------- |
| TCP:22   | 0.0.0.0/0 |
| TCP:80   | 0.0.0.0/0 |
| TCP:8080 | 0.0.0.0/0 |
| TCP:8000 | 0.0.0.0/0 |

> 3306（MySQL）、6379（Redis）**不要**公网开放，容器内互访即可。

***

## 4. 登录服务器并安装 Docker

登录服务器（本机终端）：

```bash
ssh root@<IP>
```

安装 Docker + Compose 插件（root 执行）：

```bash
apt-get update
apt-get install -y ca-certificates curl gnupg
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | tee /etc/apt/sources.list.d/docker.list >/dev/null
apt-get update
apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

验证：

```bash
docker --version
docker compose version
```

***

## 5. 上传项目代码

**方式A（无仓库时，本机执行）：**

```bash
# 在本机项目所在的上一级目录执行，把整个 shuiwu 传上去
scp -r ./shuiwu root@<IP>:/opt/
```

**方式B（有 git 仓库，服务器执行）：**

```bash
cd /opt
git clone <你的仓库地址> shuiwu
```

确认目录结构：

```bash
ls /opt/shuiwu/deploy/docker-compose.yml
```

***

## 6. 一键启动（首次构建 5\~10 分钟）

```bash
cd /opt/shuiwu/deploy
bash start.sh
```

查看状态与日志：

```bash
docker compose ps
docker compose logs -f backend
```

两条日志都无 ERROR 后，先用 IP 验证：浏览器打开 `http://<IP>` 应看到登录页（账号 `admin/123456`）。

***

## 7. 配置组件指向域名

> 项目 nginx 配置已把 `server_name` 设为 `shuiwufenxi.top www.shuiwufenxi.top _`（见 `deploy/docker/nginx.conf`）。

确认你的服务器上的这份配置已是最新（若用 git 方式 `git pull` 拉取，或重新上传该文件）。

重新构建前端让配置生效：

```bash
cd /opt/shuiwu/deploy
docker compose up -d --build frontend
```

***

## 8. 验证域名访问（=部署成功）

浏览器访问：

* `http://shuiwufenxi.top` → 登录页

* `http://shuiwufenxi.top/bigscreen` → 大屏

服务器侧自检：

```bash
curl -I http://127.0.0.1/                          # 期望 200
curl -s http://127.0.0.1/api/auth/login -X POST -H "Content-Type: application/json" -d '{"username":"admin","password":"123456"}'
docker compose ps                                  # 5 个服务均 running
```

本机 `ping shuiwufenxi.top` 返回 `<IP>` 且浏览器能打开 = **部署成功**。

> 若打不开：多为 **备案未通过** 或 **安全组未放行80/域名未解析**，逐一核对第 1/2/3 节。

***

## 9. 可选：HTTPS 免费证书

> 前提：备案已过、80 可访问。用 Let's Encrypt 自动续期。

服务器安装 certbot 并对前端容器内的域名签证书（推荐容器宿主混合方案，简化起见先用 standalone）：

```bash
apt-get install -y certbot
# 临时停掉 80 占用后签发
docker compose stop frontend
certbot certonly --standalone -d shuiwufenxi.top -d www.shuiwufenxi.top -m <你的邮箱> --agree-tos --no-eff-email
docker compose start frontend
```

证书生成于 `/etc/letsencrypt/live/shuiwufenxi.top/`。要启用 HTTPS 需把证书挂载进前端容器并添加 443 server 块（需要时可让我补充生成 HTTPS 版 nginx.conf 与 compose 挂载）。

***

## 10. 日常运维速查

```bash
cd /opt/shuiwu/deploy
bash stop.sh                           # 停止(保留数据)
docker compose down -v                 # 停止并删数据(谨慎)
docker compose restart backend         # 重启某服务
docker compose logs -f frontend        # 看日志

# 代码更新后重新发布
git pull
docker compose up -d --build
```
